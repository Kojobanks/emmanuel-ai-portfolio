# Emmanuel Harmony — AI Portfolio

A responsive, static recruiter-facing portfolio for Creative AI, AI evaluation, multimodal review and technical workflows.

## Preview locally
Open `index.html` in a browser. No dependencies or build step are required.

## Publish using GitHub Pages
1. Sign into GitHub and create a **public** repository named `emmanuel-ai-portfolio` (or another name).
2. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` to the repository root; commit them to `main`.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/(root)`, then **Save**.
5. Open the published URL shown under Pages. For a repo named `emmanuel-ai-portfolio`, the URL typically looks like `https://YOUR-USERNAME.github.io/emmanuel-ai-portfolio/`.

## Before sharing with recruiters
- Replace the email address if preferred.
- Add an approved PDF resume or a link to one (not included).
- Add real, approved screenshots/work samples; current graphics are conceptual illustrations, not product screenshots.
- Verify the description of KB Lead Engine and all client relationships for accuracy.
- Never publish API keys, .env files, client data, private conversations or internal code without permission.

Hosted content is public. GitHub Pages does not run a Python/FastAPI backend; the site is an HTML/CSS/JS showcase only.
